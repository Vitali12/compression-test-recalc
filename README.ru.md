# Пересчёт испытаний на сжатие

[English](README.md) | [Русский](README.ru.md)

Однофайловая Python-программа (GUI на Tkinter + CLI), которая пересчитывает
данные испытания на сжатие, экспортированные из испытательной машины в Excel,
и **нейтрализует податливость самой машины** по эталонной кривой «без
образца». Для серии образцов программа вычисляет напряжения, исправленные
перемещения, показатели жёсткости и модуль Юнга, показывает сводную
статистику и экспортирует отчёт в Excel и графики.

![Пример графиков](examples/Nigroz-4_общие_графики.png)

## Что делает программа

- Читает лист Excel с несколькими образцами: каждый образец — блок из трёх
  столбцов (время, сила, ход); количество образцов не ограничено.
- Использует **образец 0** («без образца»), чтобы построить кривую
  «сила — ход» машины и вычесть податливость машины из записанного хода
  каждого образца.
- Для каждого образца находит точку максимальной жёсткости системы на ветви
  нагружения (P123), разделяет записанный ход u123 на часть машины u12 и
  деформацию образца u3 и вычисляет:
  - **K3 = P123 / u3** — жёсткость образца,
  - **K = 2·K3** — исправленный показатель жёсткости,
  - **σ = Pmax / A** — предел прочности при сжатии,
  - **E = K·L / A** — модуль Юнга,
  - а также статистику по серии: среднее ± стандартное отклонение и CV.
- Два интерфейса: **графический** и **командная строка**.
- Экспорт: оформленный **отчёт Excel** (сводка, параметры, листы с кривыми
  по образцам) и **графики PNG**.

## Требования

- Python 3.10 или новее (разработано и проверено на 3.13)
- Пакеты: numpy, pandas, matplotlib, openpyxl

```bash
pip install -r requirements.txt
```

Tkinter входит в стандартный установщик Python для Windows; в Linux его нужно
доустановить (например, `sudo apt install python3-tk`).

## Быстрый старт

```bash
# GUI (открывается автоматически, если запустить скрипт без аргументов)
python recalc_compression.py

# CLI: обработка файла; рядом появятся <префикс>_results.xlsx и <префикс>_charts.png
python recalc_compression.py data.xlsx

# Примеры CLI
python recalc_compression.py data.xlsx --length 33.6
python recalc_compression.py data.xlsx --samples 1,2,3 --out K-27
python recalc_compression.py data.xlsx --sheet 2 --area 113.1 --no-machine
```

Готовый пример входит в репозиторий:
[examples/example_input.xlsx](examples/example_input.xlsx) — входной файл,
[examples/example_results.xlsx](examples/example_results.xlsx) и
[examples/example_charts.png](examples/example_charts.png) — результаты.
Пересоздать пример: `python tools/make_example_input.py`.

## Формат входного файла

Это обычный лист .xlsx/.xlsm: небольшая шапка, затем данные. Образцы
располагаются рядом, по три столбца на каждый
(`Время | Сила | Ход`):

```
      A        B       C        D        E       F        G        H       I
1   K-27                                        <- строка 1: номер серии (любой текст)
2     0                         1                         2       <- строка 2: номера образцов
3                               33.6                      34.0    <- строка 3: высота L, мм (необязательно)
4                               113.1                     113.4   <- строка 4: площадь контакта A, мм²
5   Время    Сила    Ход      Время    Сила    Ход      Время   ...    <- строка 5: заголовки столбцов
6   сек      Н       мм       сек      Н       мм       сек     ...    <- строка 6: единицы (необязательно)
7   0.0      0       0.000    0.0      0       0.000    ...             <- данные
```

| Строка | Содержимое |
|--------|------------|
| 1 | Номер серии (любой текст). |
| 2 | Номер образца для каждого блока: `1, 2, 3, …`; `0` — эталонное испытание *без* образца. |
| 3 | *(необязательно)* Высота образца L, мм. Если строки нет, L берётся из `--length` / поля в GUI / значения по умолчанию 33,6 мм. |
| 4 | Площадь контакта A, мм². Может отсутствовать — тогда задайте её через `--area` / поле в GUI. |
| 5 | Заголовки, по три на блок: `Время \| Сила \| Ход`. |
| 6 | *(необязательно)* Строка единиц `сек \| Н \| мм`; при наличии пропускается автоматически. |
| 7+ | Данные: время [с], сила [Н], ход траверсы [мм]. |

Примечания:

- Заголовки столбцов должны быть именно русскими словами `Время`, `Сила`,
  `Ход` — это шаблон выгрузки исходных данных. В ячейках данных допускаются
  запятая как десятичный разделитель и пробелы как разделители тысяч
  (`1 165,8`).
- Номера образцов могут идти в произвольном порядке; повторы автоматически
  переименовываются с предупреждением.
- Без образца 0 податливость машины не учитывается (u12 = 0), выдаётся
  предупреждение.
- Строки шапки определяются автоматически; просматриваются первые ~80 строк
  листа.

## Параметры командной строки

| Параметр | Описание |
|----------|----------|
| `xlsx` | исходный файл Excel |
| `--sheet` | лист: имя или индекс (по умолчанию первый) |
| `--length, -L` | длина (высота) образца, мм; если не указана — берётся из шапки файла (иначе 33,6) |
| `--m` | окно расчёта жёсткости, точек (по умолчанию 250) |
| `--machine-smooth` | сглаживание кривой машины, точек (по умолчанию 101) |
| `--samples` | номера образцов через запятую или `all` (по умолчанию все) |
| `--area` | площадь контакта, мм² (запасное значение, если в файле её нет) |
| `--no-machine` | не учитывать податливость машины (игнорировать образец 0) |
| `--out` | префикс выходных файлов (по умолчанию — имя исходного файла) |

## Результаты

- **Сводка в консоли** — информация о серии, параметры расчёта, таблица
  результатов, средние ± ст. откл., CV, примечания и предупреждения.
- **`<префикс>_results.xlsx`** — листы:
  - `Summary`: по строке на образец (A, L, Pmax, σ, P123, u123, u12, u3, K123,
    K12, K3, K = 2·K3, исправленные K, E, i\*, индекс пика, примечания) и
    средние по выбранным образцам;
  - `Parameters`: параметры расчёта и предупреждения;
  - `Specimen N`: кривые P, u3, u123, u12 по каждому выбранному образцу.
- **`<префикс>_charts.png`** — обзорная панель из четырёх графиков: кривые
  нагружения с эталоном «без образца» и столбчатые диаграммы σ, E и K по
  образцам со средними.

В GUI тот же отчёт и графики выгружаются кнопками **Export Excel…** и
**Export charts…**.

## Методика подробнее

1. **Эталонная кривая.** По образцу 0 берётся ветвь нагружения (до пика),
   сортируется по силе, сглаживается скользящим средним
   (`--machine-smooth`) и делается монотонно возрастающей. Интерполяция по
   этой кривой даёт u12(P) — собственный ход машины под нагрузкой P.
2. **Максимум жёсткости.** Для каждого образца вычисляется жёсткость
   k = ΔP/Δu в скользящем окне из `m` точек; точка i\* с максимальной
   жёсткостью на ветви нагружения (до пика) задаёт P123 = P(i\*) и
   u123 = u(i\*).
3. **Вычитание податливости.** u12 = u12(P123) интерполируется по эталонной
   кривой (при выходе за её диапазон — экстраполяция с примечанием);
   u3 = u123 − u12 должна быть положительной, иначе образец помечается
   ошибкой.
4. **Показатели.** K3 = P123/u3; K = 2·K3; σ = Pmax/A; E = K·L/A.
   Отсутствие A или L отмечается в примечаниях.

Синтетический пример позволяет проверить всю цепочку: при жёсткости машины
200 Н/мм и жёсткости образцов 1000/1400 Н/мм программа возвращает ровно
K3 = 1000/1400 Н/мм, K = 2000/2800 Н/мм, E = K·L/A.

## Замечания и ограничения

- При окне жёсткости по умолчанию `m = 250` блоку образца нужно более 500
  строк данных (n > 2·m); для коротких записей уменьшите `m` (например,
  `--m 50`).
- Разбор ожидает русские заголовки `Время | Сила | Ход` — см. раздел о
  формате входного файла.
- Блок с менее чем 10 строками корректных данных отклоняется.
- Строки с нечисловыми ячейками (пропуски в кривых) отбрасываются до
  расчёта.
